### About the Experiment 

This experiment provides an interactive virtual lab to visualize the Dynamic Programming solution of the Longest Common Subsequence (LCS) problem. Learners can enter custom sequences, use preset examples, and compare Standard DP and Rolling Array approaches while observing table updates, character comparisons, and backtracking behavior step-by-step.
